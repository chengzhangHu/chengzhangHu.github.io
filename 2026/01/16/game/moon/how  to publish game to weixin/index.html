how to publish game to weixin

2026-01-16

🚀 一、整体流程总览（先有全局）

从 0 到上线 = 7 步

后面 每一步我都拆到“点哪里 / 做什么”。

🧾 二、准备工作（一次性）

1️⃣ 注册微信小游戏账号（必须）

👉 网址：微信公众平台
选择类型：小游戏

你需要准备：

  • 一个微信号（管理员）
  • 身份信息（个人或企业）

⚠️ 建议：

  • 个人账号：可先验证流程
  • 企业账号：后期变现、广告、分包更自由

2️⃣ 创建小游戏 AppID

路径：

这个 AppID 非常重要，后面要用。

🧩 三、创建 Cocos Creator 2.x 项目

1️⃣ 安装 Cocos Creator 2.x

推荐版本：

  • 2.4.11（稳定、小游戏支持最好）

创建项目时：

  • 模板：2D
  • 脚本语言：JavaScript

2️⃣ 项目基础设置（关键）

项目 → 项目设置

  • 分辨率策略：SHOW_ALL 或 FIXED_WIDTH

  • Canvas：

    • 适配刘海屏
    • 开启多分辨率

🧠 四、微信小游戏适配（必须做）

1️⃣ 打开小游戏适配

Cocos 菜单：

设置项：

  • 构建平台：微信小游戏
  • AppID：填你刚拿到的 AppID
  • 启用分包（强烈建议）
  • 启用 MD5 Cache（减少更新体积）

2️⃣ 微信小游戏特殊 API

不要用的（会直接挂）

❌ DOM
❌ window.alert
❌ 本地文件系统随意写

要用微信的

Cocos 已帮你封装了大部分，只在 广告 / 登录 / 分享 时用。

🧪 五、本地调试（新手最容易卡）

1️⃣ 构建小游戏工程

点击：

生成目录类似：

2️⃣ 用微信开发者工具打开

  • 打开 微信开发者工具

  • 选择：

    • 项目类型：小游戏
    • 目录：build/wechatgame
    • AppID：填你的

✅ 看到游戏跑起来 = 成功 80%

🧱 六、你这种“长期扩关架构”的关键配置

1️⃣ 启用分包加载（强烈）

在 Cocos 构建设置里：

  • 勾选 分包

结构示例：

运行时加载：

👉 新世界 = 新分包 = 不影响老玩家

2️⃣ 热更新（进阶，可后期）

微信小游戏支持：

  • 远程 JSON
  • CDN 资源

你可以：

  • 核心代码不变
  • 替换关卡配置 / 美术

📋 七、小游戏发布前必做（合规重点）

1️⃣ 基础信息（不填会被拒）

  • 游戏名称（不要夸张、不要涉政涉金）
  • 图标（1024×1024）
  • 游戏截图（至少 3 张）
  • 游戏简介（不夸大、不承诺收益）

2️⃣ 内容合规（非常重要）

你的题材 是安全的，但注意：

✅ 可用：

  • 山海经（传统文化）
  • 神话生物（幻想）
  • 月球、科幻

⚠️ 避免：

  • 赌博
  • 现金收益
  • 明示“赚钱”“暴富”
  • 真实宗教崇拜

3️⃣ 必须有的页面

  • 开始界面
  • 玩法说明
  • 退出/返回按钮
  • 防沉迷（微信自动）

🛂 八、提交审核流程

路径：

填写：

  • 版本号
  • 更新说明（哪怕是第一次）
  • 测试账号（如果需要）

审核时间：

  • 通常 1–3 个工作日

🟢 九、发布上线

审核通过后：

🎉 恭喜，你的微信小游戏正式可玩了！

🧠 十、你这个项目的“最佳上线策略”（给你建议）

阶段 1（快速过审）

  • 一个世界（如：xxx）
  • 5–10 个关卡
  • 无广告或少广告

阶段 2（扩世界）

  • 新分包：乌蒙山
  • 新怪物：山海经
  • 不提交新代码，只更新资源

阶段 3（长期运营）

  • 活动关卡
  • 皮肤
  • 世界解锁

✅ 最后一句总结

微信小游戏不是“写完代码就完事”，
而是一个 平台型内容发布系统。
你现在的架构思路，非常适合微信生态长期演进。
